# CRISIS COMMUNICATION SOP — Tactical Recovery Protocol

> **Untuk:** @arifb.id mid-eksekusi 12 bulan, kalau ada insiden brand
> **Anchor:** `STRATEGY-REFRESH-PROTOCOL.md` (strategic-level crisis) + `REPLY-FARM-PLAYBOOK.md` (komen tactical) + `STRATEGI-PERSONAL-BRANDING.md` §5 (Voice consistency saat tertekan)
> **Tipe:** Tactical SOP untuk 4 crisis scenario yang paling mungkin terjadi Bulan 1-12
> **Voice:** "Anda" formal, deklaratif, anti-hype — TETAP konsisten saat tertekan (anti-drift voice = signature trust)

---

## FILOSOFI CRISIS COMMUNICATION

Crisis = **stress test untuk Voice + brand**. Audience ingat brand bukan dari post saat smooth, tapi dari respond saat insiden. Founder yang tetap tenang, terstruktur, dan honest saat crisis = compound trust 10x lebih cepat dari 100 post normal.

**3 Sacred rules saat crisis:**

1. **JANGAN respond dalam 1 jam pertama** — emosi tinggi, judgment rusak, makin merusak situasi
2. **JANGAN delete post tanpa proses** — screenshot existence, audience tau, delete tanpa context = guilty signal
3. **JANGAN improvise voice** — saat tertekan, kebanyakan founder switch ke defensive/casual/snarky. Itu kill brand. Voice formal "Anda" anti-hype = HARUS dipertahankan, bahkan kalau effort ekstra

**4 Crisis scenario yang paling mungkin Bulan 1-12:**

1. **Factual error di post** — fakta salah, sumber misquote, angka keliru
2. **Tone-deaf moment** — post yang accidentally menyinggung subkomunitas / context blind spot
3. **Viral negative** — post di-quote-tweet dengan negatif, thread mention 1000+ engagement
4. **Brand attack / troll** — sengaja diserang (bisa jealous competitor, troll random, atau organized smear)

---

## UNIVERSAL 3-STEP FRAMEWORK

Untuk semua scenario, eksekusi 3 step ini berurutan. Tidak skip.

### STEP 1 — PAUSE (1-3 jam)

**Objective:** Lower emotional intensity sebelum respond.

Action concrete:
- Tutup app sosmed (Threads/IG/LinkedIn) — log out kalau perlu
- Set timer minimum 1 jam, ideal 3 jam
- Pindah environment (jalan kaki, kerja offline, tidur kalau malam)
- TIDAK reply komen, TIDAK reply DM, TIDAK delete post selama timer

**Yang BOLEH dilakukan saat PAUSE:**
- Screenshot komen / quote tweet / thread untuk dokumentasi
- Tulis brain dump di Notes pribadi (BUKAN draft response, hanya emosi)
- Ngobrol dengan 1 trusted person (mentor / pasangan)

**Yang TIDAK BOLEH:**
- ✗ Reply impulsif walaupun "ada yang harus dijelaskan"
- ✗ Delete post (kecuali factual error harmful, lihat scenario 1)
- ✗ Block komen dengan alasan emosi
- ✗ Post baru saat timer aktif (apa pun isinya)

### STEP 2 — ASSESS (15-30 menit, setelah PAUSE)

**Objective:** Kategorikan severity + decide action path.

Jawab 4 pertanyaan jujur:

1. **Apa fakta sebenarnya?** — terpisah dari interpretasi audience
2. **Severity level?** — gunakan matrix di bawah
3. **Audience yang terdampak?** — subscribers? casual viewer? competitor? troll?
4. **Action paling minim yang fix situasi?** — bukan grand gesture, minimal viable response

### STEP 3 — RESPOND (sesuai scenario)

Berdasarkan ASSESS, eksekusi response per scenario di bawah.

## SCENARIO 1 — FACTUAL ERROR DI POST

**Trigger:** Anda sadar (atau di-correct audience) bahwa fakta/angka/quote di post salah.

**Severity:**
- ○ **Low** — typo nama/tanggal yang tidak ubah meaning → edit + acknowledge di komen
- 🟡 **Medium** — angka data 10-30% off → edit + 1 separate post correction
- ● **High** — quote/source attribution salah ke real person → delete + apology + DM private ke person yang di-misquote

**Response template (Severity Medium):**

```
Update: 1 angka di post ini ([angka lama]) sebenarnya [angka baru, dengan source baru]. 

Saya correct di post original. Terima kasih [@yang_correct] yang tunjukkan ini.

Lesson: saya akan double-check source untuk angka data sebelum publish, terutama yang mengklaim pattern industri.

— Arif
```

**Decision matrix:**

| Severity | Edit original? | Separate post? | Apology required? | Recovery time |
|---|---|---|---|---|
| Low | ✓ Edit | — | — | <24h |
| Medium | ✓ Edit + footnote | ✓ 1 post acknowledgement | Light | <48h |
| High | ✓ Delete + screenshot dokumentasi | ✓ 1 post apology + correction | Yes, full | 7 hari (jangan post topik lain heavy 24h) |

## SCENARIO 2 — TONE-DEAF MOMENT

**Trigger:** Post Anda tidak bermaksud menyinggung, tapi context blind spot membuat subkomunitas merasa di-dismiss / under-acknowledged.

**Severity:**
- 🟡 **Medium** — 5-10 komen surface concern → 1 acknowledgement post + private DM ke yang vocal
- ● **High** — 30+ komen kritik + quote tweet kritik dari thought leader → public apology post

**Response template (Severity High — public apology):**

```
Tentang post saya kemarin tentang [topik]:

Saya membaca kembali post itu setelah beberapa orang menulis komen / DM yang menunjukkan saya miss konteks penting tentang [aspek yang miss].

Yang saya tulis: [paraphrase original]
Yang saya seharusnya juga acknowledge: [aspek yang miss]

Saya tidak mau menyembunyikan post original (sudah edit dengan footnote). Saya mau acknowledge bahwa saya bisa lebih hati-hati di topik yang melibatkan [subkomunitas].

Terima kasih untuk yang menulis dengan honest. Voice saya berkembang karena feedback ini.

— Arif
```

**Anti-pattern:**
- ✗ "Saya tidak bermaksud menyinggung" tanpa acknowledge what was off — non-apology
- ✗ Delete post lalu pretend tidak ada — guilt signal, lose trust
- ✗ "Tapi saya juga betul soal [aspek lain]" — defensive, makes worse
- ✗ Block komentator yang vocal — censorship signal

**Decision matrix:**

| Severity | Edit? | Apology? | Public/Private | Recovery time |
|---|---|---|---|---|
| Medium | ✓ Edit footnote | Light, in komen | Mixed (public footnote + private DM) | <72h |
| High | ✓ Edit + footnote | Full apology post | Public, separate post | 7-14 hari (light posting topik mostly) |

## SCENARIO 3 — VIRAL NEGATIVE

**Trigger:** 1 post Anda di-quote-tweet dengan kritik, thread mention 1000+ engagement dalam 6-24 jam, narasi audience > narasi original Anda.

**Severity:**
- ● **High** — viral di niche kecil (1-5K engagement) → measured response 24h setelah peak
- 💥 **Critical** — viral di mainstream (10K+ engagement, news cycle picks up) → pause public posting 48-72h, response setelah peak surut

**Response strategy:**

1. **24h SILENCE rule** — jangan post apapun di platform terdampak selama 24 jam pertama. Algoritma momentum akan turun.
2. **JANGAN reply quote-tweet kritik** — engagement makin amplify viral
3. **JANGAN block kritikus** — censorship narrative makes worse
4. **PUBLISH measured response post** setelah 24-48h, kalau memang ada poin valid yang bisa di-acknowledge:

```
Tentang thread minggu ini yang membahas post saya tentang [topik]:

Saya sengaja tidak respond langsung 24 jam pertama — supaya saya bisa baca semua perspektif tanpa defensif.

3 hal yang saya pelajari:

1. [acknowledge poin valid #1]
2. [acknowledge poin valid #2]
3. [acknowledge poin valid #3 atau "saya masih dalam posisi yang sama tapi sekarang lebih hati-hati cara presentasinya"]

Saya tidak akan delete post original — itu di-screenshot, di-quote, dan saya tidak ingin pretend tidak terjadi.

Yang saya commitment: [1 concrete behavior change]

Terima kasih yang menulis honest. Brand saya berkembang lewat ini.

— Arif
```

**Anti-pattern saat viral negative:**
- ✗ Lawan setiap kritikus 1-by-1 (energy drain, escalate)
- ✗ Post 5 thread defending stance dalam 24h pertama (over-defense signal)
- ✗ DM private ke top kritikus minta delete quote tweet (manipulasi)
- ✗ Hire bot/buy comments untuk dilute negative (akan ketahuan)

**Recovery timeline:**

- **24h:** Silent
- **48-72h:** 1 measured response post (kalau valid)
- **Mgg 1:** Light posting, hindari topik terkait
- **Mgg 2-3:** Resume normal calendar, tetap reflective
- **Mgg 4+:** Full normal, integrate lessons di content baru

## SCENARIO 4 — BRAND ATTACK / TROLL

**Trigger:** Sengaja diserang — bisa jealous competitor smear, organized troll group, atau random hater dengan reach besar.

**Severity:**
- ○ **Low** — 1-3 troll dengan engagement <100 → ignore + report
- 🟡 **Medium** — competitor smear publik dengan 500-2K engagement → don't engage, double-down on signal post
- ● **High** — organized smear dengan 5K+ engagement → consider 1 measured statement, mostly silent + legal consult kalau defamatory

**Response strategy:**

1. **DON'T engage with troll** — energy drain + amplify reach mereka
2. **Double-down on signal** — post lebih banyak konten quality di hari yang sama, override troll narrative dengan signal
3. **Block selectively** — block troll yang harassing personal, tapi NOT kritikus yang substantive (beda)
4. **Document everything** — screenshot, save untuk legal kalau eskalasi

**Response template (Severity High, kalau perlu statement):**

```
Beberapa hari terakhir ada thread yang mengklaim [klaim spesifik] tentang saya / brand saya.

Klaim itu: [tidak benar / sebagian benar dengan konteks / saya tidak mau respond detail]

Yang saya akan respond cuma ini:
- [1 fakta paling penting untuk koreksi]
- [1 boundary statement: saya tidak akan engage thread itu lagi setelah post ini]

Energi saya untuk membangun, bukan defending. Lanjut yang biasa.

— Arif
```

**Decision matrix:**

| Severity | Engage? | Public statement? | Block? | Recovery |
|---|---|---|---|---|
| Low | ✗ Ignore | ✗ | Selective (harassment only) | Continue normal |
| Medium | ✗ | ✗ Optional | Selective | 1-2 hari light, lalu signal post |
| High | ✗ Don't engage thread | ✓ 1 measured statement | Selective + document | 7-14 hari, legal consult kalau defamatory |

## PRE-CRISIS PREPARATION (jaga buffer mental)

Crisis lebih mudah di-handle kalau Anda tidak burnout. Per `ANTI-BURNOUT-PROTOCOL.md`:

1. **Energy buffer mingguan** — minimum 1 hari off per minggu, no exception walau "lagi momentum"
2. **Trusted advisor cycle** — minimum 1 mentor / pasangan yang Anda bisa ngobrol saat crisis (bukan untuk setuju, untuk reality check)
3. **Anti-drift voice ritual** — re-read STRATEGI §5 (Voice & Tone) bulanan. Saat tertekan, kebanyakan founder drift dari Voice — re-anchor minggu pertama tiap bulan.
4. **Crisis playbook bookmark** — file ini = di top akses Notion / Apple Notes Anda. Saat crisis hit, buka file ini dulu sebelum respond.
