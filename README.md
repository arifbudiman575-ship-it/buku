## ATURAN GOLDEN — TIDAK BOLEH DILANGGAR

1. **Voice tenang.** "Anda" konsisten. Tidak hype, tidak caps lock berlebih, tidak emoji di Threads.
2. **3 frase signature** wajib di-repeat: *Sistem, bukan tools. Arsitek, bukan pengguna. Tools berubah, framework abadi.*
3. **4-lapis filter** untuk setiap post public-facing: book-safe, voice, signature >= 1, anti-hype.
4. **Sacred IP gates:** detail Prolog buku (Februari 2024 + saldo Rp 847.000 + 347 prompt + recovery 340%) **tidak boleh** muncul di sosmed sebelum buku rilis publik.
5. **Tracker harian wajib.** Tanpa data Day N, baseline hilang permanen.
6. **Go/No-Go gate** di T-1: kalau 1 dari 5 pertanyaan jawab "tidak", **TUNDA Day 1 +1 hari**.
7. **Decision Rules trigger** = tindakan, bukan diskusi. Lihat §12 STRATEGI.

## CARA BACA PLAYBOOK INI SELAMA 1 BULAN

### Setiap pagi (5 menit)

1. Buka [`DAILY-CHEAT-SHEET.md`](DAILY-CHEAT-SHEET.md) di HP
2. Ingat 3 frase signature + 4-lapis filter + **stranger-test** (§18.9)

### Reply Engine harian (30-45 menit) — tuas pertumbuhan tercepat (P1)

1. Balas 10-15 akun lebih besar di niche dengan **mini-framework** (bukan basa-basi "setuju kak")
2. Voice tetap "Anda"/tenang. Lihat [`STRATEGI-PERSONAL-BRANDING.md`](STRATEGI-PERSONAL-BRANDING.md) §19.3

### Saat mau posting (Day N)

1. Buka [`BODY-CONTENT-BULAN-1.md`](BODY-CONTENT-BULAN-1.md) -> Cmd/Ctrl+F cari `D{N}` -> copy body publish-ready
2. (Kalau perlu cek slot/CTA) buka [`CONTENT-CALENDAR-BULAN-1.md`](CONTENT-CALENDAR-BULAN-1.md) -> cari `D{N}` di DETAIL PER POST
3. Filter 4-lapis sebelum publish (lihat [`DAILY-CHEAT-SHEET.md`](DAILY-CHEAT-SHEET.md))
4. **Stranger-test (§18.9):** baca hook sekali — *"bekerja untuk orang yang belum kenal saya?"* Kalau terdengar seperti hook/umpan, ganti jadi anti-bait (Hook Bank §6 kategori F)
5. Publish slot WIB sesuai kalender
6. Update Tracker baris D{N} jam 22:00 WIB

### Setiap Senin pagi (15 menit)

1. Open Tracker -> Tab 2 Weekly Snapshot -> isi
2. Open Notion -> Weekly Review template -> isi audit asosiasi (5Q) + Theoderic (4Q)
3. Cek Decision Rules trigger di Tab 3
4. Tulis 3 aksi minggu ini

### Day 28-30 (akhir Bulan 1)

1. Buka [`BULAN-2-OUTLINE.md`](BULAN-2-OUTLINE.md)
2. Walk through decision tree
3. Generate Bulan 2 calendar dari pattern Bulan 1
