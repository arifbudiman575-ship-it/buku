# WORKSHEET LEAD MAGNET — DESIGN SPEC

> Spec untuk 6 worksheet PDF (Hari 1-6) yang dilampirkan di Email H1-H6 Lead Magnet.
>
> **Format:** PDF 1 halaman A4 portrait, design konsisten dengan style anchor Manifesto V1.
>
> **Aturan #1:** 1 worksheet = 1 halaman, max. Lebih = melanggar voice (Hari 5 email: "1 halaman A4. Kalau Anda perlu scroll, sistemnya belum cukup matang.")
>
> **Build deadline:** sebelum Day 7 (Min 21 Juni 2026) — saat LP go-live.

---

## 0. STYLE ANCHOR (lock dari Manifesto V1)

| Element | Spek |
|---|---|
| Page size | A4 portrait (210x297mm) |
| Margin | 20mm semua sisi |
| Background | Off-white `#F5F1EA` |
| Body text | `#1A1A1A` |
| Heading | Aksen `#1F3A5F` (biru tua) |
| Heading font | Cormorant Garamond / Playfair Display |
| Body font | Inter / IBM Plex Sans |
| Footer | `@arifb.id · Hari [N] / 7` (kanan bawah, 10pt) |
| Header (kiri atas) | "7-DAY AI ARCHITECT CHALLENGE" (kapital, sans, 9pt, abu) |

**Tools produksi:** Canva free -> export PDF Print quality.

**File naming:** `H1-audit-jujur.pdf`, `H2-audit-workflow.pdf`, dst sampai `H6-iterasi.pdf`.

## 9. ANTI-PATTERN

1. **Worksheet >1 halaman.** Hard rule. Disiplin = part of lesson.
2. **PDF interactive form fields.** Voice = tulis tangan. Form fields encourage typing. Skip.
3. **Background image ramai / texture.** Plain background. Substansi di copy.
4. **Logo besar di tengah.** Brand mark hanya di footer kecil.
5. **Watermark "Confidential" / "Do not share".** Voice anti-hype: kalau peserta share = good marketing, bukan loss.
6. **Color gradient background.** Plain solid. `#F5F1EA` saja.
7. **PDF size > 1MB.** Optimize export (Canva -> "Print PDF Standard" cukup, bukan "Print PDF Pro").
