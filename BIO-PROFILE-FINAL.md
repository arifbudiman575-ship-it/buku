## 4. PROFILE PICTURE — SPEC

> Sama di 3 platform. Kontinuitas visual = trust signal #1.

### Hard requirements

- **Foto Anda.** Bukan logo. Bukan AI-generated. Bukan ilustrasi.
- **Wajah jelas.** Crop dari atas dahi sampai bawah dagu, dengan ruang 10-15% padding di tiap sisi.
- **Latar bersih.** Solid color (off-white `#F5F1EA` atau abu muda) atau blur natural. Tidak kantor messy, tidak crowd.
- **Ekspresi tenang.** Senyum tipis OK. Tertawa lebar = tidak match voice tenang.
- **Lighting frontal.** Bukan dramatic shadows. Window light siang hari = ideal.
- **Pakaian:** simpel, neutral color, kerah rapi. Tidak kostum, tidak motif ramai.

### Soft requirements

- Resolusi minimum 800x800px (Instagram crop ke 320x320 di display, tapi source besar = future-proof)
- Format: JPG quality 85-90 atau PNG
- File size < 2MB

### Anti-pattern

- Foto wedding (terlalu formal, vibe salah)
- Foto travel dengan landmark (mengalihkan dari wajah)
- Foto grup di-crop (terlihat tidak natural)
- Foto BW dengan filter heavy (premature aging brand)
- Foto pakai kacamata hitam (anti-trust)

### Eksekusi 30 menit (kalau belum punya)

1. Pakai HP, mode portrait, kamera depan high-quality
2. Posisi dekat jendela, jam 10:00-14:00, jendela di depan Anda (bukan belakang)
3. Background: tembok bersih atau pakai sheet putih taped ke tembok
4. Take 30-50 shot, beda angle tipis
5. Pilih 1 yang ekspresinya paling tenang + paling natural
6. Edit minimal: brightness +5, contrast +5. Jangan filter heavy.

## 10. ANTI-PATTERN

1. **Ganti bio mid-sesi tanpa lock.** Bio diubah-ubah Bulan 1 = brand perception unstable.
2. **Tambah handle "Dr. / Mr. / Coach"** di nama display. Voice tenang ≠ butuh title overload.
3. **Tagline beda di tiap platform.** Sinkron 3 platform = brand recognition.
4. **AI-generated profile photo.** Trust killer #1 untuk audience profesional senior.
5. **Bio ALL CAPS.** Voice rules.
6. **Caption hashtag spam di IG bio.** Bulan 1 minimal hashtag (1-3 max).
