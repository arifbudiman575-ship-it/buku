# THREADS 30 HARI — TINGGAL COPAS (anchor + micro-take sudah dijadwalkan)

## ⛔ PENTING: JANGAN copas semua sekaligus — tiap baris = 1 POST TERPISAH

Satu "Hari N" berisi **4–5 post berbeda** yang di-publish di **jam berbeda** sepanjang hari — BUKAN satu post panjang.

**Contoh Hari 2 = 5 aktivitas terpisah:**
1. **08:00** → publish 1 post (teks slot "Pagi")
2. **Siang** → Reply Engine (balas akun lain, BUKAN posting)
3. **16:00** → publish 1 post (slot "Sore")
4. **19:30** → publish ANCHOR (thread, dari file lain)
5. **20:00** → publish 1 post (slot "Malam")

Jadi: buka daftar hari ini → **copas 1 baris saat jamnya tiba** → poles dengan gaya Anda → publish. Lalu tutup HP sampai slot berikutnya.

## 📂 ASAL KONTEN — ini "sumber" yang Anda lihat (sekarang ada link-nya)

- Baris **micro-take** (Pagi/Sore/Malam) sudah **ditulis lengkap di sini** — langsung copas, tidak perlu buka file lain.
- Baris **ANCHOR** isinya panjang (thread), jadi diambil dari file lain. Klik:
  - Anchor harian biasa → [BODY-CONTENT-BULAN-1.md](BODY-CONTENT-BULAN-1.md) → tekan Ctrl/Cmd+F, ketik kode harinya (`D2`, `D3`, dst.)
  - Anchor Long-thread (Hari 4 / 11 / 18 / 25) → [THREADS-LONGFORM-ABC-TEST.md](THREADS-LONGFORM-ABC-TEST.md)
  - Anchor Hari 1 (Manifesto) → [MANIFESTO-PINNED-V1.md](MANIFESTO-PINNED-V1.md)
- Kutipan tokoh di micro-take (mis. Korzybski, Aristoteles) **memang ditulis apa adanya di dalam post** — itu bukan link, cukup ikut di-copas sebagai bagian kalimatnya.

## 🔢 URUTAN HARIAN — biar TIDAK bertabrakan dengan kalender 30 hari

3 file, 3 peran berbeda, **anchor-nya sama persis (D1–D30)** → saling melengkapi, bukan saingan:

| Urutan | Buka file | Untuk apa |
|---|---|---|
| **1** | **file ini** — `THREADS-30-HARI-COPAS.md` | Apa yang di-post hari ini + jam berapa (checklist) |
| **2** *(opsional)* | [`CONTENT-CALENDAR-BULAN-1.md`](CONTENT-CALENDAR-BULAN-1.md) | Konteks: kenapa post ini, pilar, trust gate |
| **3** | [BODY-CONTENT-BULAN-1.md](BODY-CONTENT-BULAN-1.md) | Ambil teks ANCHOR lengkap (Ctrl+F `D{N}`) |

> File ini = **turunan dari kalender**, memakai anchor D1–D30 yang sama. Kalender = peta "kenapa"; file ini = checklist "apa + kapan". **Tidak ada konten yang bentrok** — kalau ragu, kalender yang jadi acuan struktur.

> **Target & guardrail:** ~5 sentuhan/hari = rentang cold-start 3–8 (`STRATEGI` §19.5, Rule #12). Voice "Anda", anti-bait, book-safe sudah dijaga. Tanda **🔁** = hari yang slot Sore-nya sudah saya ganti supaya tidak dobel dengan jenis anchor-nya.
