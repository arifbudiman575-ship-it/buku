# VISUAL ASSET TEMPLATE LIBRARY

> Style guide + template Canva untuk 4 jenis aset selain Manifesto: Reels/TikTok overlay, thumbnail, quote card, carousel reguler.
>
> **Wajib pre-Day 1?** TIDAK. Build Day 8-14 (Week 2), just-in-time per minggu.
>
> **Aturan produksi:** max 30 menit per aset. Lebih = simplify.

---

## 0. PRINSIP

1. **Style anchor dari Manifesto V1.** Warna, font, layout — turunkan dari Manifesto, jangan bikin baru.
2. **Konsistensi > kreativitas.** Brand recognition Bulan 1 = repetisi visual sama.
3. **Free-only.** Canva free. Google Fonts. Tidak beli aset Bulan 1.
4. **No emoji, no foto stok cliché, no AI-generated visual.** Voice tenang = visual tenang.

---

## 1. STYLE ANCHOR (lock dari Manifesto V1)

| Element | Spek |
|---|---|
| Primer 1 (background) | `#F5F1EA` (off-white warm) |
| Primer 2 (text) | `#1A1A1A` |
| Aksen | `#1F3A5F` ATAU `#5C6B3F` (lock satu) |
| Heading font | Cormorant Garamond / Playfair Display (serif) |
| Body font | Inter / IBM Plex Sans (sans-serif) |
| Margin standar | 80px atas-bawah, 60px kiri-kanan (1080x1080) |
| Footer | `@arifb.id · X / Y` (kanan bawah, 14pt) |

---

## 2. TEMPLATE 1 — CAROUSEL REGULER (selain Manifesto)

### Use case

- List post (5 tanda, 7 perbedaan, 3 prinsip)
- NEURO-ARC breakdown per prinsip
- A.R.S.I. langkah per langkah

### Variant

- **Variant A:** 5 slide (cover + 3 isi + closing)
- **Variant B:** 7 slide (cover + 5 isi + closing)
- **Variant C:** 9 slide (cover + 7 isi + closing) — max

### Layout per slide

- Cover: heading serif 64pt, subheadline 24pt, footer
- Isi: nomor besar + heading + body 30-50 kata
- Closing: 1 frase signature + signature

### Aturan

- Max 1 carousel per minggu Bulan 1
- Max 1 hari produksi (jadwalkan Sabtu siang)

---

## 3. TEMPLATE 2 — REELS / TIKTOK OVERLAY

### Use case

- Repurpose long-thread -> 30-60 detik video
- Voice-over Anda + overlay text

### Layout (1080x1920)

- Atas (200px): hook 1-baris dalam serif 56pt aksen
- Tengah: video Anda (talking head, latar bersih)
- Bawah (200px): subtitle running, sans 32pt

### Aturan produksi

- Max 30 menit edit per Reel
- Pakai CapCut free atau Canva video — pilih satu
- **Hard cap 2 Reels/minggu Bulan 1**
- Hook tertulis HARUS sama dengan opening voice

### Variant

- A: Hook static + talking head
- B: Quote card statis 5 detik + talking head + closing quote 5 detik

---

## 4. TEMPLATE 3 — QUOTE CARD

### Use case

- Cuplikan 1 kalimat dari thread Anda untuk repurpose IG feed
- Frase signature standalone

### Layout (1080x1080)

- Center alignment
- Quote serif 56pt italic
- Atribusi sans 18pt — `— Arif Budiman, The AI Architect`
- Footer `@arifb.id`

### Aturan

- 1 quote = 1 kalimat. Bukan paragraf.
- Tidak ada gambar foto di belakang. Plain background.

---

## 5. TEMPLATE 4 — THUMBNAIL (LinkedIn / IG video / YouTube nanti)

### Use case

- Kalau repurpose thread ke LinkedIn long-post (cover image)
- Thumbnail YouTube (Bulan 3+)

### Layout (1200x628 LinkedIn / 1280x720 YT)

- Headline serif 80pt — 4-7 kata max
- Foto Anda di kanan (talking pose, latar `#F5F1EA`) — opsional, boleh skip kalau quote-only
- Footer brand line: `Arif Budiman · @arifb.id`

### Aturan

- Headline max 7 kata
- Foto WAJIB profile photo Anda — bukan AI generated, bukan foto stok

## 7. FILE NAMING & BACKUP

- **Naming:** `D{N}-{type}-v1.png` (e.g., `D10-carousel-v1.png`, `D14-reels-v1.mp4`)
- **Folder lokal:** `assets/bulan-1/D{N}/`
- **Backup:** Google Drive folder mingguan
- **Canva:** simpan di folder `arifb.id Bulan 1`

## 9. ANTI-PATTERN

1. **Bikin 10 template.** Lock 4.
2. **Update style anchor di Bulan 1.** Lock V1, evaluasi Bulan 2.
3. **Reels >2/minggu.** Hard cap.
4. **Animation kompleks.** Voice tenang = motion minimal. Fade in + cut, that's it.
5. **Outsource ke designer.** Bulan 1 produksi sendiri — Anda merasakan friction, baru tahu apa yang perlu otomatisasi.
