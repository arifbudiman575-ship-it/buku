## 2. COLOR PALETTE — Dual Theme

### Light Premium — untuk Landing/Email/Sales/Document

```
Foundation:  #FAFAFA   (off-white, hangat — bukan pure white)
Text utama:  #1A1A1A   (hitam pekat — bukan #000)
Text muted:  #6B6B6B   (untuk metadata, footer, caption)
Accent:      #1E3A5F   (Deep Navy — formal, B2B-friendly)
Border:      #E5E5E5   (garis tipis, no box berat)
```

**Pakai untuk:** Landing page, Email harian, Sales page, Slide deck, Long-form essay, Document PDF, Worksheet.

### Dark Premium — untuk IG Carousel/Reels/TikTok

```
Foundation:  #1A1A1A   (hitam pekat)
Text utama:  #FAFAFA   (off-white)
Text muted:  #A0A0A0
Accent:      #D4A574   (Burnt Sand — warmth Indonesia)
Border:      #2A2A2A
```

**Pakai untuk:** IG Carousel, IG Reels overlay, TikTok video frame & caption, Cover photo dark mode, Hero section dark variation.

### Aturan Lintas Theme

**Anchor:** Accent berbeda antar theme (Navy di light, Burnt Sand di dark). Reasoning: Navy gak terbaca clear di hitam, Burnt Sand gak premium di putih.

**Konsisten:** Heading font + body font + photography style + iconography = SAMA di kedua theme.

**Anti-pattern:**
- Tidak ada gradient
- Tidak ada drop shadow
- Tidak ada warna lain (max: foundation + text + 1 accent + 1 muted)
- Tidak pakai pure white #FFFFFF (terlalu stark)
- Tidak pakai pure black #000000 (terlalu harsh)

## 3. TYPOGRAPHY SYSTEM

### Font Family

**Heading — Playfair Display** (Google Fonts, gratis)
Premium serif, paling elegan untuk "AI Architect" positioning.
- Hero headline: Bold 700
- Section title (H2/H3): Regular 400 atau Medium 500
- Backup: Georgia → Lora → Crimson Pro

**Body — Inter** (Google Fonts, gratis)
Sans-serif clean, optimal untuk layar.
- Body default: Regular 400
- Emphasis: Medium 500
- Button/CTA: Bold 700
- Backup: Source Sans 3 → Karla → system sans-serif

### Skala Ukuran

| Element | Desktop | Mobile | Line-height |
|---|---|---|---|
| Hero headline (H1) | 56-64px Playfair Bold | 32-40px | 1.15 |
| Section title (H2) | 36-44px Playfair Regular | 24-28px | 1.25 |
| Sub-title (H3) | 24-28px Inter Medium | 20-22px | 1.35 |
| Body large | 18-20px Inter Regular | 16-18px | 1.65 |
| Body default | 16px Inter Regular | 15px | 1.65 |
| Caption / footer | 13-14px Inter Regular muted | 12-13px | 1.5 |
| Button text | 16-18px Inter Bold | sda | 1 |

### Aturan
- Tidak pakai > 2 font family per layout
- Tidak pakai > 3 ukuran per layout
- Italic hanya untuk kutipan
- Justify text — JANGAN. Always left-align
- Quotation = italic + indent 24px

## 4. PHOTOGRAPHY STYLE

### Foto Anda (profile, hero, "Siapa Saya", sales page)

**WAJIB:**
- Foto manusia asli — Anda sendiri
- Latar polos (off-white, abu-abu muda, atau hitam pekat)
- Ekspresi tenang
- Pakaian: kemeja kerah putih/biru muda atau henley polos
- Hitam-putih (default) atau warna muted (saturasi -20%)
- Resolusi tinggi (min 2000x2000px untuk profile, 3000+ untuk hero)
- Minimal 5-10 foto/sesi (untuk 12 bulan)

**HARAM:**
- Stock photo
- AI-generated headshot
- Selfie HP filter beauty
- Logo brand lain visible (Apple Watch, MacBook logo, dll)
- Pakaian dengan tulisan/logo besar

### Konten Visual (carousel, post, email header, video frame)

**WAJIB:**
- Tipografi-driven (text sebagai hero, bukan image)
- Kalau ada image: minimal (texture polos, paper grain, garis tipis)
- 1 image per layout MAX

**HARAM:**
- Stock photo "happy person with laptop"
- AI imagery (robot, brain, circuit, neural network)
- Logo ChatGPT/Claude/Gemini
- Emoji di dalam visual
- Drop shadow, gradient, glow effect


*(footer email, social link, bio mini)*

Spec: Playfair Display Bold (atau Inter Bold di space sempit).

- Logo tidak diputar/dimiringkan/di-stretch
- Min size 60px height (mobile), 80px (desktop)
- White space sekitar logo: minimal 20px

## 6. ICONOGRAPHY

**Aturan:** Pakai HEMAT. Idealnya 0 icon. Kalau wajib (mis. social link):
- Icon library: Heroicons atau Phosphor Icons thin weight
- Stroke icon, BUKAN filled
- Warna: text muted (#6B6B6B di light, #A0A0A0 di dark)
- Size: 16-20px max

**Anti-pattern:**
- Tidak pakai emoji icon di carousel/email/landing
- Tidak pakai colored icon
- Tidak pakai icon yang lebih besar dari body text

## 7. ANTI-PATTERN CHEAT SHEET

Sebelum publish setiap deliverable visual, cek list:

```
[ ] Ada > 2 font family?              -> Drop ke 2 (heading + body)
[ ] Ada > 3 warna selain foundation?  -> Drop ke 1 accent + 1 secondary max
[ ] Ada gradient / shadow / glow?     -> Hapus
[ ] Ada stock photo / AI imagery?     -> Ganti dengan tipografi atau foto Anda
[ ] Ada emoji di dalam slide?         -> Hapus
[ ] Ada CAPS LOCK di body text?       -> Lower-case (kecuali wordmark sengaja)
[ ] Text rapat tanpa white space?     -> Tambah padding 80-100px
[ ] Ada logo brand AI besar?          -> Hapus (ChatGPT/Claude/Gemini logo)
[ ] Ada tulisan "BURUAN" / "DISKON"?  -> Hapus, ini visual brand premium
```

Salah satu fail -> revisi sebelum publish.
