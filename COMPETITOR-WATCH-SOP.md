## 2. WEEKLY STUDY SOP (nempel ke ritual Senin)

Tambahkan **1 blok 30–45 menit** ke ritual Senin pagi Anda (setelah `§14.2` audit asosiasi & `§16.2` refleksi Theoderic, sebelum mulai konten minggu itu).

1. **Pilih 3 akun** dari Watch List (rotasi: Minggu A = #1–3, Minggu B = #4–6, Minggu C = #7–8 + 1 cadangan). 8 akun tercakup ~3 minggu.
2. **Ambil 3 post/akun = 9 post.** Pilih sengaja: 1 outlier viral, 1 post jualan/CTA, 1 post biasa.
3. **Catat 1 baris/post** (lihat Section 3).
4. **Loloskan kandidat insight** lewat 3 gerbang (Section 4).
5. **Masukkan insight lolos** ke Hook Bank (`§6`) / bahan Reply Engine (`§19.3`) — **bukan** A/B test (Section 5).

> **Jangan bentrok dengan Reply Engine harian (`§19.3`).** Study = analitis (Senin). Reply Engine = distribusi (harian). Pisahkan waktunya.

---

## 3. APA YANG DICATAT (1 BARIS / POST)

Catat **prinsipnya**, bukan kalimatnya. Format ringkas (boleh di Notion/Sheets):

| Kolom | Isi |
|---|---|
| Akun | handle |
| Hook pattern | contrarian / confession / callout / question / list+authority |
| Format | single / thread / carousel / reel / long-form |
| Proof | angka / testimonial / personal story / authority / case study |
| CTA & arah funnel | save / comment / DM / link bio / waitlist / webinar → ke mana? |
| Sinyal engagement | **rasio reply & save** (bukan cuma like) — selaras `§15.4` network-effect |
| **Prinsip di baliknya** | 1 kalimat: *kenapa* ini bekerja (bukan *apa* yang ditulis) |

---

## 4. GERBANG INSIGHT (3 YA = LOLOS)

Sebuah insight layak dipakai hanya jika **3 jawaban "ya"**:

1. Bisa dibawa ke **voice "Anda"** tanpa hype? (`§5`)
2. **Memperkuat** (bukan mengaburkan) positioning AI Architect? (`§2.3`, `§3`)
3. Lolos **filter 4-lapis** `§0.5` (Buku / Asosiasi / Voice / Purpose)?

Salah satu "tidak" → **buang**.

---

## 5. KE MANA INSIGHT MASUK (BUKAN A/B TEST)

- **Bulan 1:** insight lolos → tambah ke **Hook Bank `§6`** atau jadi **amunisi Reply Engine `§19.3`**. **JANGAN** A/B test (volume belum cukup — `LEAD-MAGNET §6` anti-pattern #4).
- **Bulan 2+:** baru naik ke uji terstruktur via `THREADS-LONGFORM-ABC-TEST.md` (P6 — eksperimen→iterasi = A.R.S.I. untuk konten).
- Ambil **pola**, bukan kalimat. Bikin 2–3 varian dengan angle Anda sendiri sebelum dijadwalkan.

---

## 6. ANTI-PENIRU GUARDRAIL (5 ATURAN KERAS)

1. **Catat prinsip, bukan kalimat.** Dilarang simpan caption mentah untuk "dimodif sedikit".
2. **Aturan 48 jam.** Jangan posting adaptasi <48 jam setelah lihat aslinya (cegah mimikri refleks).
3. **Uji pembeda wajib.** Tiap konten punya ≥1 elemen yang **hanya Anda**: NEURO-ARC / A.R.S.I. / Riko–Citra / origin lapangan / voice "Anda".
4. **Filter "Google 5 menit"** (`§8.7` / `§17.3`): kalau bisa ditemukan via Google 5 menit → tambah POV asli atau buang.
5. **1 frase signature wajib** muncul tiap post (`§3.2`).

---

## 7. TRIGGER KE DECISION RULES (`§12`)

- **Boundary watch (#5 `dimasyoga.pw`)** mulai pakai bahasa "arsitek/sistem AI" mendekati Anda → angkat di Weekly Review; pertajam pembeda kelas (operator→arsitek). **Positioning tetap sacred** — jangan diubah.
- **Anda dapati diri meniru >1 pola dalam 1 minggu** → trigger purpose-drift (`§12 Rule #8`): STOP cadence, re-anchor ke frase signature + `§0` + `BRAND-JOURNEY-MAP.md` Q1.
- **Follower baru mismatch ICP >30%/minggu** akibat meniru hook kompetitor generic → `§12 Rule #7`: tarik balik ke konten kategori "AI Architect" spesifik.
