## PART 1 — FILTER ANTI-KONTEN-SAMPAH

> *"It's not a content problem if views good but no sales — it's an offer problem."*
> *"Tapi kalau views jelek, it's a content problem."* — Rama

### Definisi konten sampah (yang Anda HARUS hindari):

| ❌ Konten Sampah | ✅ Konten Berkualitas |
|---|---|
| "10 prompt rahasia ChatGPT" | "Kenapa 99% prompt yang Anda kumpulkan tidak menghasilkan uang" |
| "Cara cepat kaya dengan AI" | "Saya tunjukkan saldo saya Rp 847.000 dan apa yang berubah malam itu" |
| Hook bombastis tanpa substance | Hook tajam dengan insight di bawahnya |
| Konten tanpa POV | Konten dengan opini berbeda dari mainstream |
| Repurpose konten orang lain | Insight dari pengalaman/buku Anda |
| "Save dulu, baca nanti" | "Coba dalam 5 menit setelah baca ini" |
| Generic motivation | Kontemplasi jujur |

### 5 Kriteria Konten Berkualitas (Rama's Framework + Adaptasi):

Setiap konten yang Anda post **harus jawab YA** ke minimal 4 dari 5:

1. ✅ **Understandable** — ICP saya (kolektor prompt yang lelah) bisa paham?
2. ✅ **Relatable** — ICP saya bilang "iya, gue banget"?
3. ✅ **Implementable** — ada 1 hal konkret yang bisa langsung dia coba?
4. ✅ **Memorable** — kalau dia hapus konten ini, masih ada yang dia ingat?
5. ✅ **Different** — kalau saya hapus nama saya, orang masih tahu ini saya?

> **Aturan emas:** *Kalau ragu, JANGAN post. Daripada post sampah, lebih baik tidak post.*
> Tapi **jangan ragu terlalu lama** — itu jebakan kedua (overthinking).

### Hard No (jangan pernah lakukan):

- ❌ Beli followers / engagement palsu
- ❌ Copy konten kreator lain (boleh inspired, tapi jangan jiplak)
- ❌ Hook clickbait yang bertentangan dengan isi (rusak kepercayaan)
- ❌ Janji "hasil cepat" yang kontradiktif dengan filosofi buku Anda
- ❌ Comment spam di akun orang lain (bukan engagement, ini jorok)
- ❌ Endorsement tools AI yang Anda tidak pakai sendiri ("Skin in the Game" rule)

## PART 2 — STRATEGI PER-PLATFORM

### 🧵 THREADS — Authority Builder

**Mengapa Threads PERFECT untuk Anda:**
- ✅ Text-based — match dengan kekuatan Anda (penulis buku)
- ✅ Algoritma reward replies/discussion — match dengan filosofi "merancang pemikiran"
- ✅ Lebih sedikit kompetitor di niche AI Indonesia (vs IG/TikTok)
- ✅ Audience Threads = lebih thoughtful, sophisticated (cocok dengan ICP "The Tired Collector")
- ✅ Linked ke IG — auto cross-promotion

**Posting Strategy Threads:**

| Frequency | 2-4 post/hari (biasakan dari hari 1) |
|-----------|---------------------------------------|
| Best time | Jam 7-9 pagi & 19-22 malam (WIB) |
| Format ideal | 60% single short take, 30% thread (5-10 post), 10% reply ke akun lain |
| Length | Single post: 1-3 kalimat tajam. Thread: 5-15 post, satu insight per post |

**5 Format Post yang Wajib Anda Master:**

#### Format 1: SHARP TAKE (1-2 kalimat)
```
"Anda tidak butuh 1.001 prompt baru.
Anda butuh 1 cara berpikir baru."
```

```
"Setiap kali ada AI tools baru, saya ditanya 'mas, harus belajar?'
Pertanyaan yang lebih penting:
prompt yang sudah Anda kumpulkan, sudah menghasilkan apa?"
```

#### Format 2: STORY CONFESSION (3-5 baris)
```
Februari 2024, jam 2 pagi.

Saya buka folder Notion. 347 prompt. Tersimpan rapi.

Lalu buka rekening. Rp 847.000.

Itulah malam saya berhenti jadi kolektor AI.
```

#### Format 3: CONTRARIAN OPINION (1 paragraf)
```
Hot take:

"AI expert" yang post 5x seminggu tentang prompt rahasia,
99% kaya bukan karena pakai prompt itu.
Mereka kaya karena jualan prompt itu.

Ada lingkaran di situ. Anda dan saya — di luar lingkaran itu.
```

#### Format 4: THREAD — DEEP DIVE (5-15 posts)
```
Post 1 (HOOK):
Kenapa pertanyaan Anda ke ChatGPT selalu kasih jawaban generic?

Bukan karena ChatGPT-nya bodoh.
Karena pertanyaan Anda yang bermasalah.

Thread 🧵👇

Post 2:
Korzybski, 1933, mengajarkan satu hal:
"Peta bukan wilayah."

Bahasa adalah representasi realitas, bukan realitas itu sendiri.

Apa hubungannya dengan ChatGPT?

Post 3:
Coba 2 prompt ini ke ChatGPT:

A: "bisnis saya lambat"
B: "Conversion rate turun dari 2.5% ke 1.8% dalam 60 hari.
    Traffic stabil 500/hari. Harga & tim tidak berubah."

Bandingkan respons. Sama-sama ChatGPT. Hasilnya beda jauh.

[Lanjutkan sampai post 8-10 dengan insight A.R.S.I.]

Post terakhir (CTA):
Kalau Anda merasa tertampar dengan thread ini,
buku saya keluar bulan depan.
Pre-order list di bio.

Saya tidak akan kirim spam.
Hanya kirim notifikasi saat buku siap.
```

#### Format 5: REPLY-AS-CONTENT (engagement booster)
- Quote-reply post AI expert lain dengan POV Architect
- Reply original post dengan insight 1-2 kalimat
- Setiap reply = potensial dilihat audience akun tersebut

**Threads Anti-Pattern (HINDARI):**
- ❌ Selfie-only post tanpa insight
- ❌ "Good morning friends!" (kosong)
- ❌ Cuma quote tweet tanpa POV
- ❌ Post yang sama persis dengan post IG caption

### 📷 INSTAGRAM — Content Machine

**3 Format Wajib di IG:**

#### A. REELS (untuk REACH — discoverability)
- Length: 30-60 detik
- Hook 3 detik pertama: WAJIB tajam
- Format ideal: Anda bicara ke kamera, dengan B-roll pendukung
- Frequency: 3-5/minggu

**3 Hook Style untuk Anda:**

```
HOOK STYLE 1 — Confession:
"Februari 2024, saldo saya Rp 847.000.
347 prompt di Notion.
Tidak satu pun menghasilkan uang.
Begini cara saya keluar..."

HOOK STYLE 2 — Callout:
"Cek folder prompt Anda sekarang.
[pause 1 detik]

HOOK STYLE 3 — Contrarian:
"Saya akan lawan 99% AI expert di Indonesia.
[pause]
Anda tidak butuh prompt baru.
Anda butuh framework berpikir baru.
```

#### B. CAROUSEL (untuk SAVE — depth & authority)
- Slides: 7-10 slide
- Visual: konsisten warna + font (gunakan brand identity Anda)
- Slide 1 (cover): hook tajam, big text
- Slide 2-9: satu insight per slide
- Slide 10: CTA + signature

**Template Carousel "The Architect Way":**

```

SLIDE 2:
"User bertanya:
'Prompt apa yang harus saya pakai?'"

"Architect bertanya:

SLIDE 4:

Architect membangun proses."

"User mengejar tools terbaru.
Architect menyempurnakan cara berpikir."

SLIDE 6:
"User mengukur views.
Architect mengukur output bisnis."

SLIDE 10 (CTA):
"Buku 'The Architect: Book 0' — segera launching.
Pre-order list di bio.
Save post ini, baca lagi minggu depan."
```

#### C. STORIES (untuk CLOSENESS — relationship)
- Frequency: 5-15 stories/hari (sedikit-sedikit, building rapport)
- Konten: BTS layout buku, baca-baca, opini singkat, polls, Q&A
- Strategy: highlight stories per topik (Book 1 progress, Daily Architect, FAQ, Testimoni)

**5 Tipe Story yang Wajib Anda Punya:**
1. **BTS Buku** — proses layout, kovers, edit ✅ vulnerability + anticipation
2. **Daily Architect** — 1 insight per hari (snippet dari buku)
3. **Reaction** — react opini AI expert lain dengan Architect frame
4. **Polls** — "Berapa prompt di folder Notion Anda?" (build engagement & data)
5. **Q&A** — jawab pertanyaan dari Threads/comments

### "Architect or Collector? Diagnostic Quiz"

**Tujuan:**
- Build email/WA list (target 500 di Fase 2)
- Sortir "audience yang aware mereka punya pain"
- Setup untuk launch buku nanti

**7 Pertanyaan (sample):**

1. Berapa banyak prompt yang Anda simpan di Notion/Drive?
   - [ ] 0-10
   - [ ] 11-50
   - [ ] 51-200
   - [ ] 200+

2. Dalam 30 hari terakhir, berapa rupiah yang masuk ke rekening Anda
   yang BISA Anda lacak langsung dari output AI?
   - [ ] Rp 0
   - [ ] Rp 1 - Rp 1 juta
   - [ ] Rp 1jt - Rp 10jt
   - [ ] Rp 10jt+

3. Berapa kursus AI yang sudah Anda ikuti?
   - [ ] 0-1
   - [ ] 2-5
   - [ ] 6+

4. Saat AI tools baru rilis (misal: Claude Sonnet 4.5, Gemini 3, etc),
   reaksi pertama Anda?
   - [ ] Langsung coba dan adopt
   - [ ] Skeptis, baca review dulu
   - [ ] Tidak terlalu peduli, tools lama saya cukup

5. Saat Anda buka ChatGPT untuk masalah bisnis nyata, biasanya?
   - [ ] Saya ketik singkat: "bisnis saya lambat"
   - [ ] Saya jelaskan konteks 2-3 kalimat
   - [ ] Saya kasih konteks lengkap dengan angka & batasan

6. Apa yang sering Anda lakukan dengan output AI?
   - [ ] Copy paste, kirim ke klien/posting
   - [ ] Edit dulu, baru pakai
   - [ ] Saya pakai sebagai draft awal, lalu integrate ke proses saya

7. Kalau ditanya "AI menggantikan pekerjaan Anda?" — jawaban Anda?
   - [ ] Iya, saya khawatir
   - [ ] Mungkin, saya belum tahu
   - [ ] Tidak — saya yang memutuskan apa AI kerjakan

**Scoring:**

- **Mostly A's = COLLECTOR** (score 0-30)
  - "Anda di posisi yang sama dengan saya 18 bulan lalu. Buku saya menulis untuk Anda."
- **Mostly B's = TRANSITIONING** (score 31-60)
  - "Anda sudah mulai sadar pola Collector. Tinggal lompat ke Architect."
- **Mostly C's = ARCHITECT** (score 61-100)
  - "Anda sudah Architect. Buku saya akan validasi & sharpen apa yang sudah Anda intuisi-kan."

### "Funnel Broken" Diagnostic (dari Rama):

Kalau setelah 90 hari hasil tidak ideal, cek di mana macet:

| Symptom | Diagnosis | Action |
|---------|-----------|--------|
| Followers tidak naik | Konten problem | Iterasi hook & insight depth |
| Followers naik, engagement rendah | Audience misalignment | Sharpen ICP messaging |
| Engagement tinggi, list lambat | CTA tidak jelas / lead magnet lemah | Refine CTA + simplify lead magnet |
| List banyak, sales sedikit | Offer/landing page problem | Refine landing page (Diamond Persona) |
| Sales OK, retention rendah | Product problem | Improve buku content / add bonus value |

**Rule:** 1 problem di 1 layer = jangan ubah layer lain. Diagnosis dulu, baru iterasi.
